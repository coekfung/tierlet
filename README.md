# Tierlet

Tierlet is a native macOS client for [EasyTier](https://github.com/EasyTier/EasyTier).

It provides a SwiftUI interface and runs EasyTier through a one-time authorized privileged service. This preserves the standard TUN mode while avoiding repeated authentication prompts.

## Goals

- Provide a native macOS experience
- Manage multiple EasyTier networks
- Use standard TUN mode without Network Extension
- Require authorization only during initial setup
- Keep common settings simple while retaining full configuration flexibility

## Architecture

Tierlet consists of three main components:

- `Tierlet.app`: The SwiftUI frontend for network lists, details, and configuration
- `tierletd`: A privileged LaunchDaemon responsible for configuration storage and network lifecycle
- `tierlet-core`: A Rust bridge around EasyTier's multi-instance runtime

The app communicates with the privileged service through a code-signing-validated XPC interface. The EasyTier core does not expose an additional local management port.

Tierlet targets macOS 13 or later and supports both Apple Silicon and Intel Macs.

## Network Management

The home screen presents networks as cards. Each network can be started, stopped, and configured independently.

Network details include runtime status, peers, routes, and logs.

Enabled networks connect when Tierlet starts, never before user login. Quitting Tierlet normally disconnects all active networks.

## Configuration

The basic configuration editor covers common settings such as:

- Network name and secret
- Hostname
- Static IPv4 or DHCP
- Initial peers

Advanced settings are provided through a TOML editor. Advanced TOML values override matching fields generated by the basic editor. The final configuration is validated using EasyTier's own configuration parser.

Each network has a stable profile ID mapped to a stable EasyTier instance.
